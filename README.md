\# 🇩🇿 Resto DZ



\*\*"Discover. Taste. Rate. Trust."\*\*



Resto DZ is an Algerian restaurant discovery, review, rating, and ranking platform built with modern web technologies and designed for scalability.



\## 🚀 Features



\- 🔍 Restaurant search by location, category, cuisine, and price

\- 📍 Geographic search with PostGIS

\- ⭐ Multi-dimensional rating system (food, service, cleanliness, price, atmosphere)

\- ✅ Verified visits via QR codes

\- 🛡️ Anti-fake review system with trust scores

\- 📊 Smart ranking algorithm (Bayesian-style)

\- 🌐 Multilingual support (Arabic, French, English)

\- 📱 Responsive design for mobile

\- 🏪 Restaurant owner dashboards

\- 👨‍💼 Admin dashboards with full moderation



\## 📋 Prerequisites



\- Node.js >= 18

\- PostgreSQL >= 14 with PostGIS extension

\- npm
